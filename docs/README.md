# 文档索引

| 文档 | 用途 |
| --- | --- |
| [实验记录模板.md](实验记录模板.md) | 每次实验开跑前抄一份，赛后归档到 `docs/experiments/` |

## 归档命名规则

- 实验记录：`docs/experiments/YYYYMMDD-<主题>.md`
- 阶段总结：`docs/reviews/YYYY-MM-<周期>.md`
- 设计文档：`docs/design/<主题>.md`
- 踩坑记录：`docs/pitfalls/<主题>.md`
