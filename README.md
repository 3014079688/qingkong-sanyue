# bpe-demo

从零训练一个中文 BPE 分词器，看清 token 是怎么被造出来的。

## 快速开始

```bash
python train_bpe.py
```

依赖装在本地 `pydeps/`，脚本启动时自动挂载（本机沙箱不允许写入系统 `site-packages`）。

## 实验结论速览

| 分词器 | 词表 | token/字 | 生僻字丢失 |
|---|---|---|---|
| 字符级基线 | 3,911 | 1.00 | 0% |
| 自训 · 字符表起步 | 9,911 | 0.98 | **29%** |
| 自训 · 字节起步 | 9,911 | 1.18 | 0% |
| cl100k_base | 约 20 万 | 0.71 | 0% |
| o200k_base | 约 20 万 | **0.57** | 0% |

1. **语料决定词表**——本次学出的是「樂章」「吹曲」「郊廟」，全是唐诗高频词
2. **11 万字练不出好词表**——压缩率只有商用的 58%
3. **词表小了会丢字**——`智能机器人` 还原成 `智能器人`，`<unk>` 不可逆
4. **字节兜底保覆盖率但更贵**——1.18 token/字，比字符级还差
